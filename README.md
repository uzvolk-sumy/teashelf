# Чайна полиця

Вебзастосунок для iPad і телефона: полиця чаїв з бази Notion «🍵 Чайний журнал», порада, що заварити зараз, таймер проливів і журнал чаювань (база «Чаювання»).

- `index.html`, `sw.js`, `manifest.webmanifest`, `icons/` — сам застосунок (GitHub Pages).
- `apps-script/Code.gs` — міст до Notion на Google Apps Script. Токен Notion живе тільки там.

Записи спершу зберігаються на пристрої, а потім по черзі йдуть у Notion. Без інтернету полиця, таймер і записи працюють, черга відправиться, щойно з'явиться зв'язок.

## Налаштування

### 1. Інтеграція Notion (якщо ще немає)
1. notion.so/profile/integrations → «Нова інтеграція», тип «Внутрішня». Скопіюй секрет (`ntn_…`).
2. У Notion на «🍵 Чайний журнал» і на сторінці «Чайна полиця — застосунок»: «•••» → «Підключення» → вибери інтеграцію.

### 2. Скрипт Google Apps Script
1. script.google.com → «Новий проєкт». Назви його «Чайна полиця».
2. Видали вміст `Code.gs` і встав туди файл `apps-script/Code.gs` з цього репозиторію. Збережи.
3. ⚙︎ «Налаштування проєкту» → «Властивості скрипта» → додай дві:
   - `NOTION_TOKEN` — секрет інтеграції з кроку 1;
   - `APP_KEY` — будь-який довгий пароль, який ти придумаєш.
4. Повернись у редактор, вибери функцію `testConnection` і натисни ▶ «Виконати». Google попросить дозволи — дай. У журналі має з'явитися «Чаїв у „Чайному журналі“: 16».
5. «Розгорнути» → «Нове розгортання» → тип «Вебзастосунок». «Виконувати як»: Я. «Хто має доступ»: Усі. Скопіюй URL, що закінчується на `/exec`.

### 3. GitHub Pages
Settings → Pages → Source: «Deploy from a branch», гілка `main`, папка `/ (root)`. За хвилину сайт буде на `https://uzvolk-sumy.github.io/teashelf/`.

### 4. iPad
1. Відкрий адресу сайту в Safari → «Поділитися» (або «•••» → «Поділитися») → «На екран „Додому“».
2. Запусти з іконки, встав URL скрипта й APP_KEY → «Зберегти й перевірити».

Після зміни `Code.gs` треба зробити «Розгорнути» → «Керувати розгортаннями» → ✎ → «Нова версія», інакше працюватиме стара версія.
